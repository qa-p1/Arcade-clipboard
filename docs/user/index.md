# Arcade Clipboard

Arcade Clipboard is an encrypted clipboard history shared by your own devices. It has no account and no server that can read your clips.

## Three useful things to start with

- **Find something you copied earlier:** open the picker and search your recent clips.
- **Move a clip between your devices:** pair them once, then copy and paste across the mesh.
- **Keep a clip private for a while:** turn on Private mode to pause desktop capture and sending.

Copied clips are saved in encrypted local history. A clip received from another device never replaces your system clipboard unless you choose it.
